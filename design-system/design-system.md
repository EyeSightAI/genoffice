# UToOffice 设计系统 — 商务提案版式库

> 让 AI 产出「专业、多样、美观」的 PPT。核心思路：版式样式写死在 HTML 里，AI 只「选版式 + 填内容」，不做设计决策。

## 二、字体规范

| 层级 | 字体 | 字号（相对） |
|---|---|---|
| 大标题（封面） | 思源黑体/微软雅黑 Bold | 44-60px |
| 页标题 | 思源黑体/微软雅黑 Bold | 28-36px |
| 小节标题 | 思源黑体/微软雅黑 Bold | 18-22px |
| 正文 | 思源黑体/微软雅黑 Regular | 14-16px |
| 数字强调 | DIN Alternate / Arial Bold | 48-72px |

## 三、间距与层级规范

- 页面安全边距：左右 60px，上下 50px
- 卡片圆角：12px；卡片间距：20px
- 元素分组：标题区 → 内容区 → 脚注，垂直留白 24px
- 对齐：统一左对齐或居中对齐，避免混用
- 强调色面积：单页 ≤ 30%，避免花哨

## 四、版式清单（9 类内容 × 变体 = 20 个版式）

| 内容类型 | 变体数 | 版式说明 |
|---|---|---|
| 封面 cover | 3 | ①左对齐大字 ②居中+装饰条 ③全图+文字叠加 |
| 目录 toc | 2 | ①数字列表 ②卡片式 |
| 章节过渡 section | 2 | ①大数字章节 ②全色块+编号 |
| 要点列表 bullets | 3 | ①三列卡片 ②图标列表 ③编号列表 |
| 对比 compare | 2 | ①两列对比 ②表格对比 |
| 数据 data | 2 | ①大数字突出 ②图表+洞察 |
| 人物团队 team | 2 | ①横向头像卡 ②网格头像 |
| 金句引用 quote | 2 | ①大引号 ②色块引用 |
| 总结结尾 ending | 2 | ①要点回顾 ②行动号召 |

## 五、AI 使用规则（关键）

1. AI 只「选版式 + 填内容」，**不自己发明配色/布局**
2. 每个页面先判定内容类型 → 从版式库选对应 HTML 模板 → 套用配色变量 → 填真实内容
3. 同一份 PPT 内，同一内容类型尽量不重复用同一版式（保证多样性）
4. 配色全程只用选定方案的色值，不混搭
